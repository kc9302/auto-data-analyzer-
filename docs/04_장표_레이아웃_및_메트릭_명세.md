## 1. 장표 공통 디자인 시스템 (기획자 정의)

- **화면 비율:** 16:9 와이드스크린 (해상도: 1920x1080 기준 또는 PPTX 와이드 슬라이드)
- **색상 팔레트:**
  - `Primary (Navy Blue)`: `#1E293B` (타이틀, 주요 헤더)
  - `Accent (Teal/Emerald)`: `#0EA5E9` / `#10B981` (긍정 지표, 정상 상태, 주요 추천)
  - `Warning (Amber)`: `#F59E0B` (결측치 경고, 카디널리티 주의)
  - `Danger (Rose)`: `#F43F5E` (이상치 과다, PII 감지, 다중공선성 위험)
  - `Background`: `#F8FAFC` (슬라이드 배경), 카드 배경 `#FFFFFF`
- **시각적 계층 구조:**
  - 상단 15%: 슬라이드 제목, 부제목, 핵심 인사이트 1문장 요약(One-line Key Takeaway)
  - 본문 75%: 12-컬럼 그리드 기반 정보 카드 및 시각화 차트
  - 하단 10%: 데이터 출처 메타데이터, 타임스탬프, 무결성 해시(Audit Checksum)

## 4. 피어 리뷰 기반 UX 및 비즈니스 개선 명세 (UX Enhancements)

외부 시니어 PM 피어 리뷰를 거쳐 확정된 비즈니스 친화적 장표 보완 규격:

### 4.1 통계 용어 -> 비즈니스 일상어(Plain Text) 매핑 규칙
장표 내 모든 전문 통계 지표는 비전문가도 즉시 이해할 수 있는 한글 쉬운 설명을 부제/서브텍스트로 함께 병기한다.

| 전문 통계 지표 | 시스템 출력 예시 | 비즈니스 일상어 라벨 (장표 노출) |
| :--- | :--- | :--- |
| **Skewness (왜도)** | `skew: 0.12` | **"데이터 쏠림 없음 (정상 대칭)"** |
| **Skewness (왜도)** | `skew: 1.84` | **"상위 소수에 집중된 우측 꼬리 분포 (주의)"** |
| **KS-Test p-value** | `p-val: 0.984` | **"원천 데이터 왜곡 없음 (신뢰도 98.4% 검증)"** |
| **VIF (분산팽창계수)** | `VIF: 14.2` | **"다른 변수와 중복성 높음 (제거 권고)"** |
| **Nullity Correlation** | `corr: 0.82` | **"두 변수가 함께 누락되는 동반 결측 패턴"** |
| **Mutual Information** | `MI: 0.001` | **"목표 예측에 기여도 거의 없음 (노이즈)"** |

### 4.2 슬라이드 하단 자동 [Next Action Items] 영역 신설
각 장표 최하단에 "현황"에 그치지 않고 데이터 기반의 **"즉시 실행 권고사항(Next Actions)"**을 2~3줄 카드 형태로 자동 렌더링한다.

```

| 2. [비즈니스 대응] 1개월 단위 계약자(Month-to-Month)의 이탈 위험률이 가장 높으므로      |
|    장기 계약 전환 프로모션 타겟팅 우선 집행                                             |
+-----------------------------------------------------------------------------------------+
```

### 4.3 기업 브랜드 테마 커스터마이징 (`configs/theme_corporate.yaml`)
조직별 CI를 장표에 그대로 적용할 수 있도록 설정 파일 지원:
- `company_name`: 장표 헤더에 노출할 회사/팀명
