## 1. 시스템 전체 구조 및 파이프라인 (High-Level Architecture)

본 시스템은 원천 DB의 안정성을 절대 훼손하지 않는 **Zero-Impact 데이터 수집**부터 **팩트 기반 감사 로그(Audit Log) 생성**, **최적 ML 추천**, 그리고 **기획자 정의 레이아웃 기반 장표(HTML/PPTX) 생성**까지 5개 독립 모듈로 구성됩니다.

```
+-----------------------------------------------------------------------------------+
|                            [사용자 인터페이스 (CLI / SDK)]                        |
|   auto-data-analyzer run --db-url "postgresql://..." [--target "churn"] [--out]   |
+------------------------------------------+----------------------------------------+
                                           |
                                           v
+-----------------------------------------------------------------------------------+
| 1. SafeDBConnector (안전 DB 커넥터 모듈)                                          |
|  - DB 엔진/버전 자동 식별 (PostgreSQL, MySQL, SQLite, Oracle, MSSQL 등)           |
|  - Read-Only 세션 강제 & DML/DDL 차단 인터셉터                                    |
|  - 적응형 통계 샘플링 (대용량 테이블 부하 0% 방어)                                 |
+------------------------------------------+----------------------------------------+
                                           | (Read-Only Data Stream / Pandas DataFrame)
                                           v
+-----------------------------------------------------------------------------------+
| 2. FactDataProfiler (실데이터 팩트 프로파일러)                                     |
|  - 컬럼별 타입/결측/카디널리티/중복률 정량 측정                                   |
|  - 수치형 5-Number Summary, 왜도/첨도, 이상치(IQR) 탐지                            |
|  - PII(개인정보) 정규식/엔트로피 100% 감지 및 마스킹                               |
|  - 외래키 및 잠재적 조인 키 관계 유추                                              |
+------------------------------------------+----------------------------------------+
                                           |
                                           v
+-----------------------------------------------------------------------------------+
| 3. FeatureEngineeringPipeline & LineageTracker (피처 엔지니어링 & 여정 추적기)      |
|  - Step 1: Missing Imputer (결측치 정제 및 근거 산출)                             |
|  - Step 2: Categorical Encoder (차원 폭발 방지 인코딩)                             |
|  - Step 3: Outlier & Scaler (스케일링 및 왜도 개선)                                |
|  - Step 4: Feature Generator (도메인/상호작용 파생변수)                            |
|  - Step 5: Feature Selector (VIF / MI / Importance 기반 토너먼트 선별)             |
|  * 모든 스텝의 Before/After 통계를 Lineage Event로 실시간 기록                     |
+--------------------+---------------------+----------------------------------------+
                     |                     |
     (정제된 특성셋) |                     | (100% 실제 데이터 감사 로그)
                     v                     v
+-----------------------------+   +-------------------------------------------------+
| 4. MLScoutEngine (AutoML)   |   | 5. DualPresenter (장표 생성 렌더러)              |
|  - 타겟 기반 문제 자동 분류 |   |  - Single Source of Truth (run_audit.json 참조)  |
|  - 4종 이상 앙상블 벤치마크  |   |  - [Deck 1] 데이터 현황 자동 장표               |
|    (LightGBM, XGBoost, 등)  |   |  - [Deck 2] 피처 엔지니어링 여정 장표           |
|  - 교차검증 평가지표 산출   |   |  - 출력: Interactive HTML & Editable PPTX       |
+-----------------------------+   +-------------------------------------------------+
```

## 2. 핵심 컴포넌트 상세 명세

### 2.1 `SafeDBConnector` (`src/connectors/`)
- **역할:** 입력된 접속 정보(URI 또는 딕셔너리)를 기반으로 방어적 데이터베이스 세션을 수립.
- **주요 클래스:**
  - `EngineDetector`: DB URI 파싱 및 메타데이터 쿼리를 통한 RDBMS 종류(Postgres, MySQL, Maria, SQLite 등) 및 버전 식별.
  - `ReadOnlyConnection`: DB 세션 수립 시 `SET TRANSACTION READ ONLY` 및 autocommit=False 강제.
  - `AdaptiveSampler`: `COUNT(*)` 메타데이터 조회 후 5만 행 이상일 경우 DB별 최적 샘플링 쿼리(예: `TABLESAMPLE SYSTEM (n)`, `LIMIT/OFFSET` 샘플링) 자동 주입.

### 2.2 `FactDataProfiler` (`src/profiler/`)
- **역할:** 실제 데이터를 스캔하여 어떠한 과장이나 환각 없이 정량 통계 메트릭을 계산.
- **주요 클래스:**
  - `ColumnProfiler`: 데이터 타입(수치, 범주, 날짜, 텍스트), 결측 수/비율, 유니크 수(Cardinality), 중복률 계산.
  - `DistributionAnalyzer`: 수치형의 분위수, 왜도(Skewness), 첨도(Kurtosis), IQR 1.5배 기준 이상치 수 계산.
  - `PIIScanner`: 정규식 및 키워드 사전을 통한 주민번호, 카드번호, 전화번호, 이메일 탐지 및 자동 차단 목록 등록.
  - `RelationMapper`: 컬럼명 유사도(Jaro-Winkler) 및 고유값 포함 관계를 분석하여 잠재적 ER 관계 다이어그램 생성.

### 2.3 `FeatureEngineeringPipeline` & `LineageTracker` (`src/pipeline/`)
- **역할:** 투명하고 검증 가능한 피처 엔지니어링 수행 및 모든 변환 단계의 전/후 스냅샷 기록.
- **주요 클래스:**
  - `LineageTracker`:
    ```python
    class LineageEvent:
        step_id: int
        step_name: str          # 예: "Missing_Value_Imputation"
        technique: str          # 예: "Median_Imputation"
        target_columns: list    # 대상 컬럼 목록
        stats_before: dict      # 변환 전 결측률, 왜도, 컬럼 수, 메모리
        stats_after: dict       # 변환 후 결측률, 왜도, 컬럼 수, 메모리
        rationale: str          # 통계적 채택 사유
    ```
  - `StepImputer`: 수치형 중앙값/MICE, 범주형 최빈값/결측 플래그 대체.
  - `StepEncoder`: 저카디널리티(One-Hot) 및 고카디널리티(Target/Frequency) 자동 분기 인코딩.
  - `StepScaler`: RobustScaler / PowerTransformer(Yeo-Johnson) 자동 선택.
  - `StepFeatureSelector`: VIF(다중공선성) > 10 제거, 상호정보량(MI) 및 트리 기반 Feature Importance 기준 하위 피처 컷오프.

### 2.4 `MLScoutEngine` (`src/ml_scout/`)
- **역할:** 최적의 머신러닝/딥러닝 모델을 공정하게 벤치마크하고 결과를 도출하며, 학습 모델 인스턴스 보존 및 일반화 갭(과적합 위험도) 진단.
- **주요 클래스:**
  - `DataDNAProfiler`: 데이터셋 규모, 희소성, 불균형도를 측정하여 [콜드스타트 ➔ 안정기 ➔ 빅데이터 스케일업] 3단계 진화 로드맵 수립.
  - `MLScoutEngine`: GBDT(LightGBM, HistGBM), 앙상블(RandomForest, ExtraTrees), 선형 모델, TabularDeepNet 토너먼트 및 승자 모델 피팅.

### 2.5 `ServingPackager` & `CodeForge` (`src/serving/`, `src/pipeline/`)
- **역할:** 블랙박스 없이 실무에 바로 투입 가능한 순수 파이썬 파이프라인 및 실시간 FastAPI REST API 서빙 패키지 자동 생성.
- **주요 산출물:**
  - `best_model.joblib`: 직렬화된 실제 학습 머신러닝 모델 바이너리.
  - `serve.py`: Pydantic v2 기반 엄격한 스키마 검증, 단일/배치 실시간 추론 엔드포인트 및 레이턴시(ms) 텔레메트리가 내장된 고성능 FastAPI 서버.
  - `Dockerfile`: 프로덕션 경량 컨테이너 이미지(Python 3.11-slim) 빌드 명세.
  - `test_client.py`: 배포된 서빙 API의 상태 확인 및 추론을 검증하는 자동화 테스트 클라이언트.
  - `pipeline.py` & `train.py`: scikit-learn 호환 누수 제로 파이프라인 및 5-Fold A/B 테스트 재현 스크립트.

### 2.6 `DualPresenter` (`src/presenter/`)
- **역할:** 단일 진실 공급원(`run_audit.json`) 데이터를 기반으로 기획자가 정의한 고품질 시각 장표 렌더링.
- **주요 클래스:**
  - `HtmlReportBuilder`: 반응형 웹 대시보드 리포트 생성 (`dist/customers_report.html`).
  - `PptxDeckBuilder`: 핵심 4장 비주얼 모델 진단 파워포인트 생성 (`dist/customers_presentation_deck.pptx`).

## 4. 피어 리뷰 기반 기술 강화 정책 (Architecture Enhancements)

외부 수석 MLOps 엔지니어 피어 리뷰를 거쳐 확정된 기술 안전장치:

### 4.1 Data Leakage(데이터 누수) 원천 방지 절차
- **원칙:** 결측치 대체(Imputation), 스케일링, 인코딩의 파라미터는 오직 `X_train`에서만 fit 한다.
- **파이프라인 순서:**
  1. 원천 데이터 팩트 프로파일링 (전체 분포 확인)
  2. **[Train / Test Split] 분할 선행** (Stratified Split 또는 Time-based Split)
  3. `X_train`에 대해서만 `pipeline.fit_transform()` 실행 및 통계 기준값 산출
  4. `X_test`에 대해서는 `pipeline.transform()`만 실행하여 검증
  5. 교차검증(CV) 시에도 각 Fold 내부에서 독립 파이프라인 fit 강제

### 4.2 메모리 하드 리밋 (OOM Safety Guard)
- **최대 메모리 점유 한도:** `MAX_MEMORY_MB = 500MB` (기본값)
- **방어 메커니즘:**
  - 샘플링 단계에서 DataFrame 메모리 추정 (`df.memory_usage(deep=True)`).
  - 500MB 초과 시:
    1. 대용량 텍스트/비정형 BLOB 컬럼 자동 감지 후 앞 200자 Truncate 또는 메타데이터(길이, 엔트로피)로 변환.
    2. float64 -> float32, int64 -> int32 자동 다운캐스팅.

### 4.3 Native PPTX 객체 생성 원칙 (100% 수정 가능한 슬라이드)
- 장표를 단순 Matplotlib 이미지로 찍어내는 방식을 엄격히 금지함.
- `python-pptx`의 네이티브 컴포넌트 API 사용:
  - 표: `slide.shapes.add_table()`
  - 텍스트/카드: `slide.shapes.add_shape(MSO_SHAPE.ROUNDED_RECTANGLE)` 및 `add_textbox()`
  - 차트: `slide.shapes.add_chart()` (네이티브 바 차트 / 파이 차트 사용)
- 사용자가 파워포인트에서 직접 글꼴, 폰트 크기, 텍스트 내용, 표 수치를 클릭하여 수정할 수 있도록 보증.
