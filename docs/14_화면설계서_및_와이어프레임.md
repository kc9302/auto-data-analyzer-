## 1. UI/UX 디자인 시스템 및 비주얼 토큰

모든 화면(Web 대시보드, Excel 시트, PPTX 슬라이드, HTML 리포트)은 일관된 프리미엄 디자인 토큰을 공유합니다.

| 토큰 분류 | 색상 코드 (HEX) | 비즈니스 의미 및 용도 |
|:---|:---:|:---|
| **Primary Dark** | `#0F172A` (Slate 900) | 메인 헤더, 최상위 텍스트, 다크 슬레이트 타이틀 |
| **Accent Indigo** | `#4F46E5` (Indigo 600) | 1차 피처 분석 키 비주얼, 액션 버튼, 합성 처방전 |
| **Danger Rose** | `#F43F5E` (Rose 500) | 타겟 증가(+) 위험 방향성, PII 경고, 핵심 리스크 |
| **Accent Sky** | `#0EA5E9` (Sky 500) | 타겟 감소(-) 완화 방향성, 통계 보조 지표 |
| **Warning Amber** | `#F59E0B` (Amber 500) | 노이즈 변수 의심, 제외(Drop) 권고, 결측 경고 |
| **Success Emerald**| `#10B981` (Emerald 500)| 건전성 80점 이상, 데이터 100% 완전성, 최적 모델 1위 |
| **Surface Slate** | `#F8FAFC` (Slate 50) | 대시보드 배경, 카드 서브 배경, 테이블 지브라 스트라이프 |
